# Project Context Cache: Witch's Trial
Updated: 2026-10-02 18:38

## Project Overview
"Witch's Trial" is a 2D action-platformer built using C++23 and SFML 3.1.0 with a STRICTLY CUSTOM 2D kinematic physics engine and rigid body simulation. All third-party physics libraries (such as Box2D) have been removed.

## Significant Files & Architecture

### Build & Configuration
- `CMakeLists.txt`:
  - Purpose: Builds the `WitchsTrial` executable using C++23 standard.
  - Dependencies: SFML 3.1.0 (Graphics, Window, System, Audio) via CMake FetchContent.
  - Post-build: Copies `assets/` and `lib/` binaries to output directory.
- `.github/workflows/release.yml`:
  - Purpose: Cross-platform CI/CD release workflow for Windows (MSVC), Linux, and macOS.

### Audio System
- `include/Engine/Audio/AudioManager.hpp`, `src/Engine/Audio/AudioManager.cpp`:
  - Purpose: Global audio manager singleton (`AudioManager::getInstance()`) in namespace `Engine::Audio`.
  - Architecture: Manages background music streaming via `sf::Music` (with looping, stop, pause, resume, volume control) and a dynamic 32-instance pool of `sf::Sound` instances for sound effects (SFX) preventing sound cut-offs and round-robin stealing when exhausted.
  - Asset Caching & Fallback: Caches loaded `sf::SoundBuffer` instances; gracefully handles missing placeholder audio files (`mMissingBuffers`) by checking disk existence before attempting to load, preventing log spam or runtime crashes.
  - Volume Controls: Provides independent control for Master, SFX, and BGM volumes.

### Core Application & Engine
- `src/Game/main.cpp`:
  - Purpose: Entry point of the application. Instantiates `Game` and calls `run()`.
- `include/Game/Game.hpp`, `src/Game/Game.cpp`:
  - Purpose: Central application orchestrator managing the `sf::RenderWindow`, 60Hz fixed timestep accumulator loop (`fixedUpdate` decoupled from variable `update` and `render`), state stack (`mStates`), pending state changes, and window modes.
- `include/Engine/States/State.hpp`:
  - Purpose: Pure virtual base class for application states (`handleInput`, `fixedUpdate`, `update`, `render`).
- `include/Engine/GUI/Button.hpp`, `src/Engine/GUI/Button.cpp`:
  - Purpose: GUI button with selection, hover, click detection, text rendering, and audio playback.

### Graphics & Animation System
- `include/Engine/Graphics/Animation.hpp`:
  - Purpose: Pure C++23 Animation data representation supporting spritesheet frame grids (frame width/height, frame count, row offsets), explicit custom `sf::IntRect` frame sequences, virtual frame count animations, duration per frame, and looping vs. one-shot playback.
- `include/Engine/Graphics/Animator.hpp`:
  - Purpose: Animation playback manager holding a collection of named `Animation` instances. Provides `play(name, restartIfSame)`, `update(dt, sprite*)`, `applyToSprite(sprite)`, `getCurrentFrame()`, `isFinished()`, and `getProgress()`.
- `include/Engine/Graphics/ParticleSystem.hpp`, `src/Engine/Graphics/ParticleSystem.cpp`:
  - Purpose: High-performance visual effect particle system in namespace `Engine::Graphics`.
  - Architecture: Lightweight `Particle` struct (position, velocity, start/end color, lifetime, start/end scale, gravity, drag) backed by a pre-allocated pool of 2048 particles to eliminate runtime allocations.
  - Updates & Rendering: Steps positions, gravity, drag decay, and linear alpha/color interpolation independently of the heavy physics loop; renders in batched triangles using `sf::VertexArray`.
  - VFX Emitters: `emitMuzzleFlash` (directional sparks and smoke for Gun mechanic), `emitPogoTrail` (magical sparkles for traveling pogo orb), `emitPogoBurst` (massive radial shockwave burst on melee pogo strike), `emitDashTrail` (fading silhouette ghost particles during Witch air-dash and Beast pounce), `emitBloodSplatter` (directional blood droplets on enemy/player melee and ranged impacts), `emitDebrisBurst` (wood splinters and dust when props are destroyed), `emitParrySparks` (radial metallic deflection sparks on successful parry), and `emitRoarShockwave` (expanding crimson shockwave ring for Beast Roar).
- `include/Engine/Graphics/FontManager.hpp`, `src/Engine/Graphics/FontManager.cpp`:
  - Purpose: Global font manager singleton (`FontManager::getInstance()`) in namespace `Engine::Graphics`.
  - Architecture: Preloads and categorizes fonts into `FontType::Title` (Dark Fantasy serif, e.g., Cinzel), `FontType::Pixel` (Retro pixel-art, e.g., PixeloidSans), and `FontType::Default` (general UI fallback) with candidate discovery paths and fallback mechanisms.
  - Pixel-Perfect Rendering: Applies `font.setSmooth(false)` to retro pixel fonts preventing sub-pixel blurring in retro viewports; provides `roundPosition()` and `roundCoord()` inline helpers to align text rendering coordinates to integers.

### Custom Physics Engine
- `include/Engine/Physics/AABB.hpp`:
  - Purpose: Mathematically sound Axis-Aligned Bounding Box (AABB) struct supporting overlap tests, containment, expansions, swept broadphase, center/half-extents calculations.
- `include/Engine/Physics/SweptAABB.hpp`:
  - Purpose: Continuous Collision Detection (CCD) algorithm using Minkowski-expanded bounding box slab raycasting. Returns `SweptHit` with normalized Time of Impact (`toi` in `[0, 1]`), surface collision normal, and contact point. Prevents tunneling during high-velocity movement (e.g. dash/pounce).
- `include/Engine/Physics/RigidBody.hpp`:
  - Purpose: Custom 2D rigid body representation supporting Static, Kinematic, and Dynamic body types, `ColliderTag` classification (`SolidWall`, `OneWayPlatform`, `Hazard` / `MothFloor`, `Generic`), one-way platform toggling, linear momentum, inverse mass, restitution, friction, forces, and impulses. Supports explicit inverse mass override and mass for kinematic bodies.
- `include/Engine/Physics/PhysicsWorld.hpp`, `src/Engine/Physics/PhysicsWorld.cpp`:
  - Purpose: Core custom 2D physics simulation world. Features broadphase overlap filtering, narrowphase minimum penetration derivation (`CollisionManifold`), iterative impulse solver for normal and Coulomb friction forces, Baumgarte positional stabilization, CCD dynamic movement protection, raycast/sweep queries (`sweepTest`, `raycast`), spatial queries (`queryAABB`, `checkOverlap`), and debug rendering.

### Combat System, Projectiles & Spells
- `include/Game/Combat/CombatBoxes.hpp`:
  - Purpose: Lightweight `Hitbox` (damage, poiseDamage, knockback, active flag) and `Hurtbox` (active flag, invulnerable/i-frame support) structures with custom `Physics::AABB` math and `checkOverlap()` query.
- `include/Game/Entities/Projectile.hpp`, `src/Game/Entities/Projectile.cpp`:
  - Purpose: Ranged magic bolt and projectile entities (`Standard`, `Gun`, `PogoOrb`, `Thunder`). Handles trajectory movement with continuous collision detection (`PhysicsWorld::sweepTest`) destroying projectile on static colliders (walls), damage & poise infliction on enemy impact with stagger support, locked vertical velocity (`velocity.y = 0`) on PogoOrb for straight flight, safe-exit check (`bool mHasPlayerExited = false;`) in `Projectile::update` preventing player self-damage while continuously overlapping from cast until fully exiting AABB, balanced stats (55 base damage to enemies, 95 struck damage, exactly 10 self-damage if player re-enters AABB), electric shock lightning bolt for Thunder applying Electrified status and Staggered state, and multi-layer glowing particle rendering.
- `include/Game/Entities/IceWall.hpp`:
  - Purpose: Temporary solid ice pillar entity created via Ice Magic ('L'). Registers a static `RigidBody` in `PhysicsWorld` (`ColliderTag::SolidWall`), enabling wall sliding and wall jumping. Has a 4.0s max lifetime and destroys upon taking damage from player attacks, enemy attacks, or projectiles.

### Game States
- `include/Game/States/MenuState.hpp`, `src/Game/States/MenuState.cpp`:
  - Purpose: Main menu with Start, Options, and Exit actions. Handles modal popups.
- `include/Game/States/GameState.hpp`, `src/Game/States/GameState.cpp`:
  - Purpose: Active gameplay state. Holds `PhysicsWorld` and steps it within 60Hz `fixedUpdate()`, loads TMX map and static colliders, manages Player, spawns enemies and boss via `ObjectManager`, runs combat collision resolution, tracks camera with lerp and dynamic screenshake, supports Hit-Stop freeze frames (`triggerHitStop`, pausing 60Hz physics/movement simulation on heavy impacts while continuing rendering), and draws world, HUD, continuous F3 auto-aim targeting laser, and debug overlays. Dynamic prop boxes/crates spawning has been removed in `loadLevel` to focus on aerial combat.
  - Game Over & Victory Loop: Manages `GameEndState` (`GameOver`, `Victory`). Triggers "YOU DIED" cinematic overlay upon player death and "VICTORY ACHIEVED" upon boss defeat with letterbox bars and fade-in stylized text.
  - Restart Logic: Fluid hold 'R' restart fades screen to black over 1s (alpha 255), triggers level reset (`restartGame()`) and continues resetting in background while 'R' is held, then smoothly fades back to transparent on release. Enter key can also reset during end screens.
  - Debug Hitboxes & Targeting Laser (F3): When F3 is toggled, draws all collision boxes and a continuous targeting laser line from the player to the currently locked-on nearest enemy (demonstrating auto-aim in real-time); completely hidden during normal gameplay.
  - Combat Collision Resolution: Resolves player attacks against enemies, enemy attacks against player (negated when parrying with `mPlayer.isParrying()`, granting 40 Rage, 2.0s enemy Stagger, and parry spark burst), and offensive Dash impacts deducting additional 25 Stamina (+10 Mana) penalty.
- `include/Game/States/PauseState.hpp`, `src/Game/States/PauseState.cpp`:
  - Purpose: In-game pause overlay state.
- `include/Game/States/EquipmentState.hpp`, `src/Game/States/EquipmentState.cpp`:
  - Purpose: Semi-transparent overlay state pushed on top of `GameState` via 'I'. Pauses active gameplay physics/animations while displaying interactive tabbed panels for Grimoire magic selection (Arcane Gun [15 MP], Pogo Magic Orb [30 MP], Ice Wall [25 MP], Thunder Strike [20 MP], Spirit Slash [20 STA]), attribute stat upgrades (Health, Mana, Stamina), and relic charms. Equipping an 'L' spell syncs directly with `Player::setActiveSpell`.

### Entities & Kinematic Movement (FSM, Dual-Form & Combat)
- `include/Game/Entities/PlayerState.hpp`:
  - Purpose: Base abstract class for player FSM (`enter`, `exit`, `handleInput`, `fixedUpdate`, `getName`, `getType`). Defines `PlayerForm` (`Witch`, `Beast`) and `PlayerStateType` (`Idle`, `Run`, `Airborne`, `Dash`, `Pounce`, `MeleeAttack`, `HeavyStrike`, `CastSpell`, `Gun`, `Parry`, `Roar`).
- `include/Game/Entities/PlayerStates.hpp`, `src/Game/Entities/PlayerStates.cpp`:
  - Purpose: Concrete player movement and combat states strictly enforcing high-mobility control scheme:
    - Input Scheme: W (Jump), A/D (Move), S (Plunge/Drop down), Shift (Dash/Pounce), J (Melee), K (Gun [15 MP]), L (Pogo-Magic [30 MP] / Beast Roar [25 Rage]), C (Parry), E (Interact).
    - `PlayerIdleState`: Ground friction, transition to Run/Jump/Dash/Pounce, Melee/Gun/Pogo/Parry (Witch) or Beast Roar (Beast 'L' with 25 Rage).
    - `PlayerRunState`: Horizontal acceleration, ground clamping, transition to Idle/Airborne/Dash/Pounce, Melee/Gun/Pogo/Parry (Witch) or Beast Roar (Beast 'L' with 25 Rage).
    - `PlayerAirborneState`: Variable jump apex hang-time, fast fall, wall sliding/jumping (supports IceWall static bodies), ceiling corner correction, S for fast downward plunge, and functional Double Jump (Air Jump). During external impulses (`isExternalImpulseActive()`), the 'W' key vertical multiplier is locked/ignored so knockback/bounce heights are unaffected by holding or releasing 'W'.
    - `PlayerDashState`: Witch Form purely horizontal Air-Dash (Left/Right only) consuming 25 Stamina, granted invulnerability frames (i-frames). Hitting an enemy deals damage, causes massive upward recoil bounce (-700px/s), triggers external impulse protection, instantly resets double jump and dash cooldown, and applies additional 25 Stamina (+10 Mana) penalty.
    - `PlayerPounceState`: Beast Form heavy action: forward leaping Pounce or downward Ground Smash with impact pause, activating attack hitbox.
    - `PlayerMeleeAttackState`: Witch Form 3-hit melee combo ('J') consuming 20 Stamina with hitbox synchronized to animation frame index and input buffering (`mAttackBuffered`). Hit 1: 45px push / 25 dmg / {36,38} box; Hit 2: 75px push / 30 dmg / {40,40} box; Finisher (Hit 3): 140px push / 50 dmg / {48,46} box with 0.6s melee lockout cooldown and instant resets for double jump and dash cooldown. Supports rapid combo chaining upon pressing 'J' during active recovery with a strict minimum 0.3s delay between hits for methodical rhythm. Features Melee Magnetism (forward velocity pull toward enemies within 160px during startup). Features Air-Stall: locks vertical velocity to 0 and suspends gravity during airborne slashes. Strikes PogoOrb to trigger massive upward velocity impulse (-820px/s), shatters IceWalls, and immediately resets double jump, dash cooldown flags, and triggers external impulse protection. Completely eliminates backward recoil on melee hit (zeroing x velocity so player stays in place).
    - `PlayerHeavyStrikeState`: Beast Form poise-breaking claw arc with hitbox synchronized to animation frame index, massive poise damage (45), and forward lunge. Rage generation removed on swing startup; rage is strictly awarded upon dealing damage.
    - `PlayerGunState`: Witch Form auto-aiming gun ('K') consuming strictly 15 Mana with 0.5s cooldown. Locks onto nearest enemy, replenishes aerial double jump and dash cooldown in the air, applies 0.07s air-stagger freeze suspending velocity/gravity, and applies strong backward/upward physics recoil impulse.
    - `PlayerParryState`: Witch Form timed parry counter stance ('C') with 0.20s parry window and 0.30s total duration. Completely negates incoming damage via `mIsParrying` check in `Player::takeDamage`. Counter reward in `GameState`: 40 Rage, 2.0s enemy Stagger with posture break, and radial metallic spark burst.
    - `PlayerRoarState`: Beast Form AoE crowd-control roar ('L') consuming 25 Rage with 1.0s cooldown. Performs an invisible 240px circular AABB query forcing all enemies caught in radius into a 3.5s Staggered state (poise break) with 15 damage and light knockback, accompanied by an expanding crimson shockwave particle ring (`emitRoarShockwave`).
- `include/Game/Entities/Player.hpp`, `src/Game/Entities/Player.cpp`:
  - Purpose: Player entity with FSM delegation, dual-form transformation, Souls-like combat resources, spritesheet animation system, active spell selection (`ActiveSpell::PogoOrb`, `IceWall`, `Thunder`), and health pool:
    - **Health**: 100 max, `takeDamage()` applying backward knockback without flipping sprite facing direction, distinct upward impulse (-440px/s), brief stagger (0.10s hit-stop), external impulse protection (`triggerExternalImpulse(0.4f)`), and instantly resetting double jump and dash cooldowns. Damage completely negated when parrying (`mIsParrying`). Instant death triggered by `triggerHazardDeath()` upon contact with hazard/moth floor colliders.
    - **Witch Form**: Stamina (100 max, 35/s regen after 0.8s delay, spent by Air-Dash and light slashes; penalty via `deductStamina`), Mana (100 max, spent by Gun [15 MP] and Pogo-Magic [30 MP], passive regen disabled; refilled only on save points/reset). 3-hit combo tracking (`mComboStep`, `mComboWindowTimer`, `mMeleeCooldownTimer`).
    - **Beast Form**: Rage Meter (initialized to 100 on transition). Dealing damage replenishes Rage (inside hit detection logic) and delays decay by 1.5s (`resetRageDecayDelay(1.5f)`). Consumed by Roar (`consumeRage(25.f)`). If no damage is dealt for 1.5s, Rage decays at 18/s. If Rage hits 0, instantly forces transformation back to Witch form. HUD pulses the Rage bar when below 25%.
    - **Environmental Dynamics**: Ground detection in `moveWithSweptCCD` detects `ColliderTag::IceModifier` (drastically lowers ground friction to <= 0.03 via `mIsOnIce`) and `ColliderTag::TrampolineModifier` (reflects downward falling velocity into massive upward bounce impulse with `-std::max(850.f, std::abs(velocity.y) * 1.5f)`, resets double jump and dash cooldown).
  - Hazard Collision: Swept CCD and AABB overlap tests check for `ColliderTag::Hazard` / `MothFloor` to invoke `triggerHazardDeath()` instantly.

### Level & Collision
- `include/Game/World/Map.hpp`, `src/Game/World/Map.cpp`:
  - Purpose: Tiled TMX map parser with automated collider generation (`generateColliders`). Merges contiguous horizontal tiles into single static `RigidBody` colliders (`SolidWall`, `OneWayPlatform`, `IceModifier`, `TrampolineModifier`, `Hazard`/`MothFloor`, and `Spikes` occupying the lower half with height = 16, offset y + 16). Batched `sf::VertexArray` rendering per tileset layer with in-game hiding of technical logic tiles (ts_main IDs 1-16), and animated Moth VFX with dark infected miasma and fluttering moth silhouettes rendered exclusively over death hazard blocks (Tile 13 MothFloor / Spikes) when unblocked from above. Standard safe platforms and solid walls remain clean without dark haze. Parses Tile 15 markers into `mPendulumTrapSpawns`.
- `include/Game/World/ArenaTrigger.hpp`:
  - Purpose: Spatial AABB trigger for Souls-like boss arena lock.
