# Witch's Trial Player Manual

## Gameplay Overview

Navigate through precision platforming maps, avoid lethal void tiles and spikes, reach checkpoints, and touch the level exit portal.

## Controls

| Key | Action |
| --- | --- |
| [A] / [D] or Left / Right | Move Left / Right |
| [Space] | Jump / Bunny Hop |
| [Shift] | Dash |
| [S] or Down | Drop through one-way platforms |
| [W] or Up | Interact (checkpoints, exit portal) |
| [R] | Respawn at checkpoint |
| [F3] | Toggle Debug Overlay and HUD |
| [F4] | Toggle Fullscreen |
| [Escape] | Pause / Return to Menu |

## Settings and Configuration

The in-game Settings menu allows adjusting:
- Window Mode: Windowed, Borderless Fullscreen, Exclusive Fullscreen.
- VSync: Enable or disable vertical synchronization.
- FPS Lock: Unlimited, 30, 60, 90, 120, 144, 165, 180, 240, 300 FPS.
- Timestep Mode: Dynamic or fixed tick rates (30Hz to 300Hz).
- Auto Bunny Hop: Continuously buffer jumps when holding Space.
- Graphics Backend: Auto, Vulkan, DirectX 12, Metal, OpenGL.
